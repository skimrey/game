================================================================================
                           QUICK START GUIDE
================================================================================

1. START SERVER
   $ python3 -m http.server 8000

2. OPEN IN BROWSER
   http://localhost:8000

3. PLAY GAME
   • WASD or Arrows to move
   • Space to jump
   • R to restart level
   • Reach gold marker to advance

4. DEVELOP
   • Edit src/ files (no build needed)
   • Refresh browser to see changes
   • Run: npm test
   • See DEVELOPMENT.md for guides
